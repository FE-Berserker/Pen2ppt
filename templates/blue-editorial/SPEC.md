# 企业蓝 · 极简编辑风 · 设计规范

> **适用场景**：工作汇报、技术分享、课程讲解。
> **画幅**：1280 × 720（16:9）· **风格**：极简白 + 雪松灰 + 一抹企业蓝，衬线斜体点睛

本套模板由社区模板（青绿编辑风）做**内容不变的高级视觉重制**而来：10 种页型与全部占位文字保持原样，视觉语言整体替换为苹果企业白体系。

## 设计令牌

令牌已作为变量存入 `.pen`，改色 / 改字体一处生效。引用方式：`$变量名`。

| 变量 | 值 | 用途 |
|---|---|---|
| `$accent` | `#2563EB` | 唯一强调蓝：眉标、斜体行、数字单位、徽章、CTA、表头线 |
| `$accent-deep` | `#1D4ED8` | 深蓝：Logo / CTA 渐变末端 |
| `$ink` | `#0A1D3A` | 标题 / 强调文字 |
| `$gray` | `#64748B` | 正文 |
| `$faint` | `#94A3B8` | 页脚、图注、来源行 |
| `$line` | `#0A1D3A0F` | 细分隔线、内框、卡片描边 |
| `$tint` | `#F6F8FB` | 面板底色、表格斑马纹、页面渐变末端 |
| `$paper` | `#FFFFFF` | 页面底色 |
| `$font-display` | Inter Tight | 展示标题（800，负字距 -0.5~-3） |
| `$font-body` | Inter | 正文 / 标签 |
| `$font-serif` | Instrument Serif | 衬线斜体：封面副题、数字单位、幽灵字、侧栏题 |
| `$font-mono` | JetBrains Mono | 代码、眉标导航、来源行 |

**字号阶梯**：封面主标题 64-72 / 致谢 48 / 页标题 30(800) / 目录标题 30 / 数据数字 44(700) / 斜体副题 38 / 正文 14-16 / 标签 10-11（大写 + 宽字距 1.5-2.4）。

**版面**：左右边距 80；页标题区 y=64–148（眉标 → 标题 → 题线）；正文区 y≥170；页脚 y=678（细线 + 左章节右页码，10px）。内框 inset 28 + 四角角标（封面/目录/致谢必有，内容页角标可选）。

## 页面类型与用法（10 种）

每页 = 一个顶层 frame。做新页时**复制最近似的页型**再改文字，不要从空白页重画。

| 页型 | 结构与要点 |
|---|---|
| 01 封面 | 顶栏（Logo+品牌+导航）→ 眉标 → 特粗标题 + 蓝色衬线斜体副题 → 汇报人/日期 → 数据统计行（竖分隔线）→ 徽章胶囊 + CTA。数据行只放**有叙事意义的数字**（本页即 10 页型/2 组字体/100% 可编辑） |
| 02 目录 | 衬线斜体幽灵 Contents + 蓝色编号圆圈 2×5 + 条目 + 行细分线。条目 ≤10，4–8 字 |
| 03 关于 | 长文页：正文 15px/1.8 行距，右侧 tint 侧栏（衬线斜体题 + mono 来源） |
| 04 正文·双栏 | 左文右图。配图圆角 12 + 图注（图：xx · 来源） |
| 05 正文·品字 | 上文 + 下双图并列 |
| 06 引用盒 | tint 面板 + 3px 蓝色竖线 + quote 图标 + 引文，面板内可用细线分段 |
| 07 代码 | 深色面板 + 编辑器标题栏（红黄绿点 + 文件名）+ JetBrains Mono 语法色。每页 ≤10 行，长了拆页 |
| 08 流程 | 4 个 tint 步骤框（lucide 图标 + 标题 + 一行说明）+ 箭头，**终结框实心蓝白字**；步骤 >4 时整排复制重排 |
| 09 表格 | 表头墨字加粗 + 2px 蓝色表头线 + 斑马纹行（tint）+ 行细线。≤5 列 × 6 行 |
| 10 致谢 | 居中特粗致谢语 + 衬线斜体英文 + 光线 + 联系文案 |

## 文案语言

- **标题 = 结论**：写「交付 12 项需求，按期率 100%」，不写「工作汇报（三）」。
- **每个数字都要有出处**：数据行/大数字必须能在本页或讲述中说清含义，禁止无指向的装饰数字。
- 一页一个核心观点；正文短句化。

## Do / Don't

**Do ✅**
- 复制页型改文字；新增元素用 `$accent` 或中性色。
- 斜体只用于：封面副题、数字单位、幽灵字、侧栏题 —— 四处，别滥用。
- 数据行沿用「大数字 + 斜体单位 + 大写标签 + 竖分隔线」语法。

**Don't ❌**
- 不要标题下划线色条、左侧书挡色条、方块要点符号、等大数字卡片阵 —— 这些都是被点名禁止的"AI 廉价感"元素。
- 不要第二种强调色；全片只有蓝与雪松灰阶（代码语法色除外）。
- 不要拉伸图片；配图统一圆角 12 + fill 裁剪。
