# 深空科技风（Dark Tech）· 设计规范

> **适用场景**：技术分享、架构讲解、产品 / 功能发布。
> **画幅**：1280 × 720（16:9）· **风格**：深空蓝黑 + 青色辉光 + 玻璃卡片（Linear 风）

与 `blue-editorial`、`minimal-business` 共享**同一内容清单**（10 种页型，占位文字一致），只是皮肤不同。

## 设计令牌

令牌已作为变量存入 `.pen`，改色 / 改字体一处生效。引用方式：`$变量名`。

| 变量 | 值 | 用途 |
|---|---|---|
| `$accent` | `#22D3EE` | 强调青：眉标、斜体行、数字单位、图标、表头线 |
| `$accent-deep` | `#6366F1` | 靛蓝：辉光、渐变末端 |
| `$ink` | `#FFFFFF` | 标题 / 强调文字 |
| `$gray` | `#FFFFFFA6` | 正文（65% 白） |
| `$faint` | `#94A3B8` | 页脚、图注、导航 |
| `$line` | `#1E293B` | 细分隔线、玻璃卡描边 |
| `$tint` | `#111A2E` | 玻璃卡片底、斑马纹 |
| `$paper` | `#050B1F` | 页面底（另有径向渐变 `#0A1F3D→#050B1F`） |
| `$font-display` | Inter Tight | 特粗标题（800，负字距） |
| `$font-serif` | Instrument Serif | 衬线斜体：副题、数字单位、幽灵字 |
| `$font-body` | Inter | 正文 / 标签 |
| `$font-mono` | JetBrains Mono | 代码、导航、页脚 |

**深色专属家具**：双层辉光（靛蓝右上 + 青色左下，`$halo` 透明度级）、80px 网格点阵（5% 白）、四角青色角标、底部渐变辉光线、代码面板 `#0D1526` + `$line` 描边。

## 页面类型（10 种，与其他皮肤一致）

封面 / 目录 / 关于 / 正文·双栏 / 正文·品字 / 引用盒 / 代码 / 流程（终结框为实心深青 `flowSolid`）/ 表格 / 致谢。结构与其他皮肤完全一致，仅令牌不同。

## Do / Don't

**Do ✅**：深底上文字只用 `$ink`/`$gray`/`$faint`；辉光与网格保持极低透明度；斜体仅那四处。
**Don't ❌**：不要浅色面板块（玻璃卡除外）；不要第二种强调色；不要纯白底；每个数字必须有出处。
