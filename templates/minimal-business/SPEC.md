# 暖米杂志风（Mocha Editorial）· 设计规范

> **适用场景**：工作汇报、年度总结、偏人文气质的分享。
> **画幅**：1280 × 720（16:9）· **风格**：米色纸面 + 砖红点缀 + 衬线标题的杂志编辑感

与 `blue-editorial`、`dark-tech` 共享**同一内容清单**（10 种页型，占位文字一致），只是皮肤不同。页型结构与用法见下；内容明细参照 teal-editorial 原版。

## 设计令牌

令牌已作为变量存入 `.pen`，改色 / 改字体一处生效。引用方式：`$变量名`。

| 变量 | 值 | 用途 |
|---|---|---|
| `$accent` | `#C1502E` | 砖红：眉标、斜体行、数字单位、徽章、CTA、表头线 |
| `$accent-deep` | `#8B5A3C` | 赭石：Logo / CTA 渐变末端 |
| `$ink` | `#2A1810` | 标题 / 强调文字 |
| `$gray` | `#4A3A30` | 正文 |
| `$faint` | `#A89888` | 页脚、图注 |
| `$line` | `#2A18101F` | 细分隔线、内框 |
| `$tint` | `#EDE3D2` | 面板底色、斑马纹 |
| `$paper` | `#F3EBDE` | 米色页面底 |
| `$font-display` | Source Serif 4 | 衬线标题（本皮标题为衬线，区别于蓝色系） |
| `$font-serif` | Instrument Serif | 衬线斜体：副题、数字单位、幽灵字 |
| `$font-body` | Inter | 正文 / 标签 |
| `$font-mono` | JetBrains Mono | 代码、页脚、来源行 |

**版面与家具**：左右边距 80；页标题区 y=64–148（脉冲点眉标 → 标题 → 题线）；页脚 y=678（细线 + 左章节右页码）；四角角标 + 封面/致谢内框。衬线斜体只用于：封面副题、数字单位、幽灵字、侧栏题。

## 页面类型（10 种，与其他皮肤一致）

封面 / 目录（幽灵 Contents + 编号圆圈 2×5）/ 关于（长文 + tint 侧栏）/ 正文·双栏（左文右图）/ 正文·品字（上文下图×2）/ 引用盒（tint 面板 + 砖红竖线 + quote 图标）/ 代码（深色面板 + 红黄绿标题栏 + JetBrains Mono）/ 流程（tint 步骤框 + 实心砖红终结框）/ 表格（衬线表头 + 砖红表头线 + 斑马纹）/ 致谢。

## Do / Don't

**Do ✅**：复制页型改文字；标题保持衬线；新增元素只用砖红与暖灰阶。
**Don't ❌**：不要冷色（蓝/青）；不要阴影渐变卡片阵；不要方块要点符号；每个数字必须有出处。
