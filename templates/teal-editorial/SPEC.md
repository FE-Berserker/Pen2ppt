# Teal Editorial（青绿编辑风）· 设计规范

> **适用场景**：工作汇报、技术分享、课程讲解 —— 页型最丰富的一套（10 种），图文混排能力强。
> **画幅**：1280 × 720（16:9）· **风格**：青绿横带 + 幽灵英文大标题 + 白底编辑排版

本文件由社区模板整理而来（原 `Custom_ppt_template.pen`）。**注意：该文件的色值为硬编码、未使用变量**，改色需逐处替换，色值以下表为准。

## 设计令牌

| 色值 | 角色 | 用途 |
|---|---|---|
| `#339999` | 品牌青绿 | 封面/致谢横带、标题下划线、目录编号圆圈、表格表头、流程图终结框、引用框竖条 |
| `#F0F9F9` | 浅青底 | 流程图步骤框底色 |
| `#333333` | 墨色 | 正文、标题 |
| `#444444` | 深灰 | 次级标题 |
| `#666666` / `#888888` | 中灰 | 次要说明文字 |
| `#E0E0E0` | 浅灰线 | 分隔线、表格框线 |
| `#F5F5F5` | 斑马纹 | 表格隔行底色 |
| 代码页 | — | 深底面板 + `#F5E0DC`（桃）/ `#CBA6F7`（紫）语法色 |

**字体**：中文正文 / 标题 = Noto Sans SC；西文与数字 = Inter；代码 = Courier New。
**版面**：左右边距约 96；页标题在左上，下压青绿短下划线；正文区从 y≈150 开始。

## 页面类型与用法（10 种）

每页 = 一个顶层 frame（本模板的 frame 用语义化命名）。做新页时**复制最近似的页型**再改文字。

| frame 名 | 页型 | 结构与用法 |
|---|---|---|
| `Frame` | 封面 | 青绿横带（页面中上部）+ 白字主/副标题；底部居中汇报人、日期 |
| `tocPage` | 目录 | 浅灰幽灵大字「CONTENTS」+ 青绿编号圆圈，双列 10 项以内 |
| `aboutPage` | 纯文字页 | 标题 + 下划线 + 段落正文，适合"关于 / 背景 / 说明" |
| `page1` | 正文·双栏 | 左文右图。图片为远程 URL 填充，**替换成自己的图**（建议本地 `images/` 引用） |
| `page2` | 正文·品字 | 上文 + 下双图并列，图文并重 |
| `page3` | 引用盒子 | 青绿竖条引用面板（含图标 + 引文 + 出处），上下可接段落 |
| `codePage` | 代码块 | 深色圆角面板 + 语法色代码（Courier New），标题说明代码主题 |
| `flowPage` | 流程图 | 4 个步骤框（浅青底）+ 箭头 + 图标，**终结框为实心青绿白字**；步骤超过 4 个时整排复制重排 |
| `tablePage` | 表格 | 青绿表头白字 + 斑马纹行，4–5 列 × 5 行内最佳 |
| `thanksPage` | 致谢 | 青绿横带 + 致谢语 + 英文小字 + 底部一行联系文案，与封面呼应 |

## 文案语言

- 标题编号式：「1. 正文（双栏布局）」——页标题带序号和括号说明，沿用此风格。
- 标题 = 结论；正文短句化，一页讲清一件事。
- 目录条目 4–8 字名词短语，10 项以内。

## Do / Don't

**Do ✅**
- 替换图片时保持原有裁剪模式（fill），不要拉伸变形。
- 新增表格行沿用斑马纹（白 / `#F5F5F5` 交替）。
- 代码行多的话拆页讲，不缩字号。

**Don't ❌**
- 不要引入第二种主题色；全片只有青绿 + 中性灰阶（代码语法色除外）。
- 不要把封面/致谢的青绿横带用于内容页。
- 不要删 `tocPage` 的幽灵 CONTENTS——它是这套模板的识别元素。
